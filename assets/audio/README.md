# Audio Zika Fighter

Ce dossier est l'emplacement attendu pour les fichiers MP3 du pack de test.

Le dépôt GitHub public ne contient pas les 58 MP3 fournis dans la conversation, notamment les morceaux de Street Fighter II. Ils ne sont pas publiés ici.

Pour tester le jeu sur un PC :
1. Télécharger le dépôt via **Code → Download ZIP**, puis extraire le projet.
2. Extraire les six parties du pack audio téléchargées depuis la conversation.
3. Copier le contenu du dossier `assets/audio/` du pack dans ce dossier `assets/audio/` du projet local, sans créer de sous-dossier supplémentaire.
4. Lancer `Lancer-ZikaFighter-avec-son.bat` à la racine du projet.

**Attention :** la création de ce dossier sur GitHub ne transfère pas les MP3 installés sur le PC. Les essais sur un site hébergé nécessitent des fichiers audio publiés avec les droits de diffusion appropriés.
